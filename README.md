# Ten Actions at Fontainebleau

A marketing activities plan for the Château de Fontainebleau, built as the companion to our
A1 poster for the INSEAD MIM28 Marketing Practicum (Leveraging Data for Marketing Science,
Section E01, Group 11). The poster carries a QR code; this is what it points at.

**Live site:** https://edav8.github.io/fontainebleau-ten-actions/

## What is here

| | |
|---|---|
| `index.html` | the whole page: the estate, the scroll story, the ten |
| `actions.js` | **the ten actions.** The poster reads this same file, so the two cannot drift |
| `model/`, `vendor/` | the procedural three.js model of the estate, and three.js itself |
| `v/` | the three château sequences, encoded with a dense keyframe interval so they scrub |
| `booklet.pdf` | Flamme's Royal Stamp Trail, the artefact for action 2 |

## Editing the ten

Everything a reader sees about an action comes from one entry in `actions.js`:

```js
{ n:3, p:[-332,56,-30], short:'Tell the queue', stage:'gate',
  cost:'low', costL:'A board, a sign and a clipboard',
  t:'Tell the queue what it is waiting for',
  where:'Grille d’Honneur · the queue', area:'Ticketing and the visit room',
  saw:'...', gap:'...', change:'...', measure:'...' }
```

- `p` is the position in the estate model, in metres: x east, z south, y up. The pin floats
  at `y`, with a dotted stalk down to the ground so it still names a building.
- `stage` is `before` | `gate` | `inside` — which band the action sits in on the poster.
- `cost` is `free` | `low` | `one`; the cost claim in the header is counted from these, so it
  cannot contradict the cards.
- `art` attaches a built artefact: `{img:'flamme.png', ...}` or `{href:'booklet.pdf', ...}`.

Change the array, commit, and the site follows. Regenerate the poster from the same file with
`tools/make-poster.mjs` in the build folder.

## Status

The ten are **drafts**, taken from our own Module 1 value-chain analysis of 12 October 2026,
and not yet agreed by the group. Pin locations are provisional. The page says so in its footer.

A student marketing proposal prepared for a course. Not affiliated with, commissioned by or
endorsed by the Château de Fontainebleau. The estate model is an original procedural
reconstruction, schematic and not a survey; the film sequences were generated by us.
